# История изменений структуры данных

## Версия 1.2.0 
### Добавлено
- Поле `priority` (приоритет заявки)
- Поле `estimated_delivery` (предполагаемая дата доставки)
- Индекс для ускорения поиска по статусу и приоритету

### Изменено
- Переименованы поля `from` → `from_location`, `to` → `to_location`
- Расширен список возможных статусов

## Версия 1.1.0 
### Добавлено
- Поле `driver_name` (имя водителя)
- Поле `cargo_value` (стоимость груза)
- Поле `insurance_required` (требуется ли страховка)

## Версия 1.0.0 
### Добавлено
- Базовая таблица `orders`
- Таблица `tracking_events` для истории событий
